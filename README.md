# PocketShop Server

Карманный «XAMPP» для Android: PHP 8.5 + MariaDB + OpenCart 4 прямо на телефоне, без root и без Termux.

## Как пользоваться

1. Скачай `PocketShopServer.apk` из релиза **latest** (раздел Releases) и установи.
2. Нажми **Запустить**. Первый запуск дольше: распаковываются PHP, MariaDB и OpenCart и создаётся база.
3. Нажми **Установщик OpenCart** и введи:
   - Hostname: `127.0.0.1`
   - Username: `root`
   - Password: пусто
   - Database: `opencart`
   - Port: `3306`
4. После установки нажми **Удалить папку install** и открывай магазин или админку.

**🤖 ИИ-мастер** — чат с ИИ, который сам правит сайт: шаблоны, CSS, базу. Умеет смотреть скриншоты страниц, принимает фото (📎) — например, для логотипа или товара. Работает через Google Gemini (бесплатный ключ на aistudio.google.com), GLM от Z.ai (бесплатные Flash-модели, ключ на z.ai) , Claude (платный ключ на console.anthropic.com) или локальную модель прямо на телефоне (llama.cpp, Qwen3, офлайн). Ключи хранятся только на телефоне.

**🔄 Авто** — режим по умолчанию: сам находит лучшие бесплатные модели (каталог OpenRouter, Gemini, GLM, локальная) и переключается на следующую, если одна упёрлась в лимит или сломалась.

**🧠 Память и 📚 база знаний** — ИИ сам записывает удачные рецепты и предпочтения (видны в каждом новом чате), ищет подсказки во встроенной шпаргалке по OpenCart 4 и в страницах из интернета, которые можно добавить по ссылке. Меню чата → «Память ИИ» / «База знаний».

**🐙 GitHub** — «Отправить» заливает сайт (htdocs/) и дамп базы (db/opencart.sql) в твой репозиторий, «Забрать» стягивает правки обратно на телефон, загружает обновлённую базу и чистит кеш. Нужен fine-grained токен с Contents: Read and write. Внутри есть git, он доступен и в терминале.

**💾 Бэкап** — база и файлы сайта в один zip в «Загрузки/PocketShop».

**Терминал** — встроенная консоль на движке Termux (без root): `php`, `mysql` (клиент MariaDB, сразу к локальной базе), `www` — перейти в папку сайта, плюс все стандартные команды Android (`ls`, `cp`, `unzip`…). Внизу клавиши ESC/CTRL/ALT/TAB/стрелки.

На Realme/OPPO нажми «Не убивать в фоне» и включи в настройках приложения автозапуск и работу в фоне, иначе система может выключить сервер.

Галочка «Доступ из Wi-Fi сети» открывает сайт для других устройств в сети (адрес появится на экране).

## Как это устроено

- PHP: пакет из Termux (bionic, видит DNS Android), встроенный сервер `php -S` с 4 воркерами.
- MariaDB: пакет из репозитория Termux, только `mariadbd` и нужные ему `.so`.
- Всё скачивается в CI (`scripts/fetch_runtime.sh`) и упаковывается в assets APK.
- `targetSdk 28`: иначе Android 10+ запрещает приложению запускать бинарники из своей папки (так же делает Termux). Из-за этого APK не подходит для Google Play, только для ручной установки.
- Только arm64 (почти все современные телефоны).

## Сборка

Каждый push запускает GitHub Actions: сборка → артефакт → релиз `latest`.
Локально: `bash scripts/fetch_runtime.sh && ./gradlew assembleRelease` (нужен Android SDK).

Ключ подписи `app/vaila.keystore` лежит в репозитории, чтобы обновления ставились поверх. Для публичного распространения замени его на свой.

## ChatGPT

Для новых настроек ИИ-мастера по умолчанию выбран ChatGPT через OpenAI API. В меню чата → «Ключ и модель» выбери ChatGPT, введи свой API-ключ и модель. Сохранённый ранее выбор провайдера сохраняется. ChatGPT использует инструменты файлов, shell, базы знаний и скриншотов сайта.

API оплачивается отдельно от подписки ChatGPT и имеет лимиты запросов и бюджета. При исчерпании квоты проверь баланс на platform.openai.com. За один запрос агент выполняет до 40 шагов; затем можно написать «продолжай».
